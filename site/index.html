WHAT IS ON THE TAPE

The game keeps the BSD Hangman noose, seven-error drawing order, and BSD-3-Clause program licence. The Spectrum port adds partial screen updates, three beeper cues, four word-length modes, and compressed dictionaries sized separately for 48K and 128K.

Dictionary data retains its own upstream terms. Read the sources and licences before redistributing a tape.
